# Year-1-Computer-Science

A collection of beginner Python practice exercises to learn Python from scratch.

## Python

The `Python/` folder contains short, self-contained scripts that cover the core language fundamentals:

| File | Topic |
|------|-------|
| `01_hello_world.py` | Printing output to the screen |
| `02_variables.py` | Variables, data types, and arithmetic |
| `03_control_flow.py` | if / elif / else and logical operators |
| `04_loops.py` | for loops, while loops, break, continue |
| `05_functions.py` | Defining and calling functions |
| `06_lists.py` | Lists, list methods, list comprehensions |
| `07_dictionaries.py` | Dictionaries and key-value pairs |

### How to run a script

```bash
python Python/01_hello_world.py
```
